# Практикум по C#

## Запуск
1. Установить .NET 8 SDK.
2. Открыть терминал в папке `Practicum`.
3. Запустить `dotnet run`.
4. Выбрать уровень и задание.

## Задания
| Уровень | Номера |
|---------|--------|
| Базовый | 1–15 |
| Средний | 16–35 |
| Продвинутый | 36–50 |

Git-задания описаны в `git-notes.md`. Тег из задания 48 ещё нужно отправить на GitHub.

## Тесты
`dotnet test Practicum.Tests/Practicum.Tests.csproj`

## База данных
- `database/init.sql` — создание базы и тестовые данные.
- `database/sql-notes.md` — задания 1–27, результаты нужно проверить в SSMS.
- `dotnet run --project database/PracticeDbApp/PracticeDbApp.csproj` — задания 28–30.

Для SQL-приложения нужна переменная окружения `PRACTICE_DB_CONNECTION`.

**Внимание:** запуск `init.sql` удалит и пересоздаст базу `PracticeDB`.
