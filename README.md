# Практикум по C#

## Запуск
1. Установить .NET 8 SDK.
2. Открыть терминал в папке `Practicum`.
3. Запустить `dotnet run`.
4. Выбрать уровень и задание.

## Статус заданий
| Уровень | Номера | Статус |
|---------|--------|--------|
| Базовый | 1–15 | Выполнено |
| Средний | 16–35 | Код готов, осталось проверить сборку |
| Продвинутый | 36–50 | Код готов, нужна проверка; Git-тег ещё не отправлен |

Git-задания описаны в `git-notes.md`.

## Тесты
`dotnet test Practicum.Tests/Practicum.Tests.csproj`

## База данных
- `database/init.sql` — создание базы и тестовые данные.
- `database/sql-notes.md` — SQL-задания 1–27, результаты нужно проверить в SSMS.
- `dotnet run --project database/PracticeDbApp/PracticeDbApp.csproj` — задания 28–30.

Для SQL-приложения нужна переменная окружения `PRACTICE_DB_CONNECTION`.

**Важно:** запуск `init.sql` удалит и пересоздаст базу `PracticeDB`.

## Заметки
**Уровень 1.** Было непросто разобраться с путями и Git. Научился работать с циклами, массивами и строками.

**Уровень 2.** Разбирался с наследованием, интерфейсами и LINQ. Понял, как разделять задачи на классы.

**Уровень 3.** Потренировался с async/await, JSON и тестами. Самое сложное — работа с историей Git.
