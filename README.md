# Практикум по C# и SQL Server

Консольные задания по C# и работа с базой данных PracticeDB.

## Запуск

Нужен .NET 8 SDK. Из корневой папки репозитория:

```bash
dotnet build
dotnet run --project Practicum/Practicum.csproj
```

В меню нужно выбрать уровень, затем номер задания. Для возврата — `0`.

Тесты задания 45:

```bash
dotnet test Practicum.Tests/Practicum.Tests.csproj
```

Для базы данных есть `database/init.sql` и `database/sql-notes.md`.

1. Открыть `database/init.sql` в SSMS и выполнить скрипт.
2. Запросы заданий 1–27 находятся в `database/sql-notes.md`.
3. Для заданий 28–30 задать переменную окружения `PRACTICE_DB_CONNECTION` и запустить:

```bash
dotnet run --project database/PracticeDbApp/PracticeDbApp.csproj
```

**Важно:** `init.sql` пересоздаёт базу `PracticeDB` и удаляет её прежние данные.
