# Практикум по C#

Репозиторий с выполненными заданиями.

## Инструкция по запуску
1. Установите .NET 8 SDK.
2. Откройте терминал в папке `Practicum`.
3. Выполните команду `dotnet run`.
4. Выберите нужный уровень и номер задания в меню.
